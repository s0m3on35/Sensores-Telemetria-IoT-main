# Sensores, Telemetria Generica y Recoleccion Territorial IoT

Carpeta preparada para GitHub Pages. Abre `index.html` para acceder a la visualizacion interactiva del curso.

## Archivos

- `index.html`: visualizacion principal.
- `style.css`: estilos de interfaz.
- `main.js`: navegacion, buscador, deep links y animaciones.
- `assets/`: imagenes extraidas de la practica de infraestructura IoT.

## Temario

- Taxonomia de sensores territoriales.
- LoRaWAN, NB-IoT y alternativas de comunicacion.
- Clases LoRaWAN A, B y C.
- NB-IoT/LTE-M, SIM/eSIM, PSM y eDRX.
- WiFi, Zigbee, Z-Wave y comparativa malla/estrella.
- Estrella/deep sleep frente a malla cooperativa y peaje energetico.
- Matriz comparativa de conectividad.
- Spec 01: nivel de rio con radar, 4-20 mA y LoRaWAN privado.
- Specs 02-03: smart parking urbano y vinedo Rias Baixas.
- Ciclo de vida, calibracion y mantenimiento.
- Energia, bateria, modos sleep y MTBF.
- Gemelo digital territorial y supervivencia de la capa fisica.
- Gateways, servidores de red y payload formatters.
- Fog/edge computing y seguridad hardware en dispositivos de borde.
- Orquestacion de flotas con LwM2M y MQTT.
- Falacia del texto en LPWAN: serializacion binaria frente a JSON completo.
- Ingenieria de payload, bit-packing y documentacion de decoders.
- Tacticas de transmision: silencio, umbrales, eventos criticos y deep sleep.
- Seguridad fisica y eficiencia energetica.
- Pentesting defensivo y securizacion de sensores, gateways, payloads, backend y firmware.
- Red side / blue side aplicado a IoT territorial: pruebas autorizadas, deteccion, respuesta e indicadores.
- Red team IoT profesional: reglas de engagement, adversary emulation, TTPs por capa, laboratorio, detection pack, KPIs, evidencias y purple team.
- Arquitectura segura de referencia con planos de datos, gestion, seguridad y observabilidad.
- Errores tipicos de diseno IoT: JSON excesivo, confirmed uplinks, gateway unico, cobertura teorica, claves y decoders.
- Auditoria de firmware IoT: analisis estatico, dinamico, hibrido, emulacion y fuzzing.
- Inyeccion de codigo en IoT inalambrico: frames, parsers, firmware malicioso y criticidad.
- Threat modeling para IoT movil/logistica digital: tracking, condicion, fraude y fallos no maliciosos.
- Practicas de arquitectura IoT y TTN.
