Imagenes usadas por la visualizacion de GitHub Pages.

## Archivos

- `caso-1.png`: caso territorial rural con sensorizacion distribuida.
- `caso-2.png`: puntos remotos dispersos en orografia compleja.
- `caso-3.png`: edificios municipales e interiores.

## Criterios

- Mantener nombres estables porque `docs/index.html` los referencia directamente.
- Evitar capturas con claves, tokens, DevEUI/AppKey reales o datos personales.
- Preferir imagenes 16:9 para evitar recortes en la maquetacion.
